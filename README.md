# DIAS Platform

**Digitaler Intelligenter Assistent** - Mockup startpage with glass morphism design.

## Quick Start

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000)

## Features

- 🎨 Glass morphism design system (4-tier)
- 🎯 7 AI module mockups
- 📱 Fully responsive
- ⚡ Smooth animations

## Tech Stack

- Next.js 15 + TypeScript
- Tailwind CSS
- Framer Motion
- Lucide Icons
